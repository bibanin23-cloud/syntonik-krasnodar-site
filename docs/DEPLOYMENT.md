# Размещение на syntonik-krasnodar.ru

Рабочие версии сохраняются в приватном GitHub и локальном предпросмотре. Домен, DNS и действующий сайт не меняются. По прямому указанию пользователя перенос на домен выполняется только в самом конце, после утверждения всех экранов и всего сайта. Готовность исходников и сохранение в GitHub не означают разрешение на переключение домена.

1. Выбрать хостинг со статическими файлами и HTTPS. Публикуемая директория — public/. Обеспечить выдачу index.html для /blog/ и /legal/*/.
2. Подготовить предварительную версию на отдельном адресе хостинга для финальной проверки, сохранив действующий домен без изменений.
3. Создать серверный POST /api/leads и согласовать канал доставки и хранения заявок. Не размещать токены в клиентском коде.
4. Добавить окончательные юридические тексты, версии согласий, серверную валидацию, ограничение запросов; заменить режим проверки формы на отправку. Протестировать фактическое получение заявки.
5. Добавить видео, инструкцию и статьи; выполнить общую визуальную корректировку и оптимизировать подготовленные изображения. FAQ и все фотографии товаров уже подключены.
6. Проверить mobile/desktop, фокус и закрытие dialog, контакты, PDF, обработку ошибок.
7. Удалить noindex только у готовых страниц, обновить robots.txt и добавить sitemap.xml. Для юридических заглушек оставить noindex до замены текстов.
8. После явного утверждения всего сайта пользователем отдельным финальным этапом подключить домен по DNS-инструкциям выбранного провайдера. До этого не менять DNS, перенаправления или размещение действующего сайта.

Не включать аналитику или рекламные cookies до согласования их списка и политики.
