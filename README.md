# Syntonik Краснодар

Начальная реализация сайта ЭнерДар, официального дилера Syntonik в Краснодаре. Самостоятельный адаптивный сайт без сторонних зависимостей.

## Запуск
Node.js 22+: `npm start`. Открыть http://127.0.0.1:4173. Проверки: `npm test`, `npm run check`. Каталог `public/` — готовые статические файлы для размещения; этап сборки не нужен.

## Реализовано
11 секций, контакты, каталог с переключением топлива и фиксированными ценами, расчёт сценариев 10/20/30%, формы заказа и звонка с проверкой данных, страницы блога и юридических документов. Подключены доступные фото и три PDF.

## Ограничения
Формы не отправляют данные: сервер и юридические тексты ещё не подключены. Недостающие материалы обозначены заглушками. Фоны автомобилей пока не очищены; этикетки требуют сверки тёмно-оливковых линий. Текстовый знак временный. Все 11 утверждённых экранов и FAQ уже получены; их дизайн ещё предстоит перенести в текущий функциональный каркас. Порядок и расчёты уточнены в ТЗ. Промежуточная версия закрыта от индексации.
