# Syntonik Краснодар

Адаптивный сайт ЭнерДар, официального дилера Syntonik в Краснодаре. Самостоятельные HTML/CSS/JavaScript без внешних зависимостей. Все 11 экранов реализованы по утверждённым макетам; первые три прошли согласование, оставшиеся подготовлены к общей корректировке.

## Запуск

Node.js 22+: `npm start`. Предпросмотр http://127.0.0.1:4173. Каталог public/ содержит статические файлы; сборка не нужна. `npm test` проверяет формулы, `npm run check` — синтаксис, ссылки, 20 фотографий, FAQ и порядок экранов. В ограниченной среде без запуска дочерних процессов: `node --test --test-isolation=none tests/calculator.test.mjs`.

## Реализовано

Белые и серые сцены, компактная прозрачная/матовая шапка с настоящим SVG-логотипом, бутылки на постаментах первого экрана, шесть автомобильных кейсов, описание и механизм продукта, калькулятор чистой экономии в месяц/год и годовой дозировки. Каталог переключает четыре топлива и пять настоящих фотографий фасовок. Подключены пять PDF с реальными превью, 30 ответов FAQ, фото Игоря, контакты и чёрный подвал. Формы заказа и обратного звонка используют отдельные наборы полей и согласий.

## Следующий этап

Общая визуальная корректировка экранов 4–11 на компьютере и телефоне. Последняя браузерная проверка ограничена политикой инструмента, поэтому полную свежую визуальную приёмку пока нельзя считать выполненной. RUTUBE, инструкция, статьи и юридические тексты ожидаются. Формы не отправляют заявки до подключения сервера и окончательных согласий; доступны прямые контакты. Перед размещением нужна оптимизация изображений и проверка фактической доставки заявок. Предпросмотр закрыт от индексации.

Домен и DNS не менялись. Перенос на домен выполняется только последним этапом после явного утверждения всего сайта пользователем.
